% image-net post, figure 9 (Tan & Le 2019, EfficientNet, Fig. 2): model
% scaling. A network is drawn as a stack of stages; a block's width is its
% channel count and its height its spatial resolution. (a) baseline;
% (b) width scaling, more channels; (c) depth scaling, more layers (each
% stage repeated); (d) resolution scaling, larger input and feature maps;
% (e) compound scaling, all three at once by a fixed ratio.
% Schematic: sizes are illustrative, as in the paper. Every stage is a conv
% stage, so all blocks are fa (the post's conv colour).
% Block geometry (panel centres x = 0 92 162 236 336): baseline widths 8 14 25
% 34 42, heights 16 12 8 4.5 2.8; (b) widths x2; (c) each stage twice;
% (d) heights x1.7; (e) widths x1.3, heights x1.25, each stage twice.
